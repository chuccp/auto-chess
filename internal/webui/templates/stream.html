SSE 实时思考过程

事件序列

start → depth × N → result → done
eventdata说明
startgame / engine / difficulty / timeLimitMs / maxDepth / turn连接建立，思考开始
depthdepth / score / nodes / timeMs / best / pv完成一层迭代加深时推送
result与 /api/v1/move 的 data 相同最终走法；随后连接关闭
errorok:false / error.code / error.message思考或参数错误
doneok / timeMs / depth / nodes / gameOver流结束标记

EventSource（GET）

FEN 棋种可直接把局面放进 URL；大棋盘请用 POST + fetch 读取流。

const fen = "rnbakabnr/9/1c5c1/...";
const url = `/api/v1/move/stream?game=xiangqi`
  + `&fen=${encodeURIComponent(fen)}`
  + `&difficulty=master&timeLimitMs=6000`;

const es = new EventSource(url);

es.addEventListener("start", (e) => {
  console.log("start", JSON.parse(e.data));
});

es.addEventListener("depth", (e) => {
  const p = JSON.parse(e.data);
  console.log(`depth ${p.depth} score ${p.score}`, p.best);
});

es.addEventListener("result", (e) => {
  console.log("best move", JSON.parse(e.data).move);
  es.close();
});

es.addEventListener("done", () => es.close());

大棋盘用 POST + fetch

网格棋种的 board 数组较大，用 POST body 更稳妥；用 fetch 的流式读取解析 SSE 帧。

const res = await fetch("/api/v1/move/stream", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    game: "gomoku",
    board: board,       // flat 225-cell board
    turn: "b",
    difficulty: "master",
    timeLimitMs: 6000
  })
});

const reader = res.body.getReader();
const decoder = new TextDecoder();
let buffer = "";

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value, { stream: true }).replace(/\r\n/g, "\n");
  let cut;
  while ((cut = buffer.indexOf("\n\n")) >= 0) {
    const frame = buffer.slice(0, cut);
    buffer = buffer.slice(cut + 2);
    const event = (frame.match(/^event: (.+)$/m) || [])[1];
    const data = (frame.match(/^data: (.+)$/m) || [])[1];
    if (!event || !data) continue;
    const payload = JSON.parse(data);
    if (event === "depth") console.log("search progress", payload);
    if (event === "result") console.log("final move", payload.move);
  }
}

为什么高难度需要它：master 可能在 6 秒内完成 6–8 层思考。depth 事件让前端知道服务没有卡死，也能展示“当前看到的最佳走法”如何随深度变化。服务端每 5 秒发送一条 SSE 注释作为心跳；客户端断开后思考会被取消。
