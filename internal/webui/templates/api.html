POST /api/v1/move 核心

传入当前棋盘与行棋方，返回 AI 选择的最佳走法、评估与思考信息。

无状态JSONCORS
POST GET /api/v1/move/stream SSE

同样的局面请求，用 SSE 流式推送每一层思考过程，最后返回 result。

text/event-stream心跳可取消
POST /api/v1/apply-move 对弈

无状态地应用一步棋，返回新棋盘、轮次、状态与合法走法；供 在线对弈 页面更新局面。

无状态返回完整局面CORS
POST /api/v1/legal-moves

返回指定局面的全部合法走法，便于落点提示或规则校验。

GET /api/v1/games

棋种目录，含棋盘元数据、初始局面、规则和坐标约定。

GET /api/v1/games/{game}

单个棋种的完整元数据。HTML 详情页为 /games/{game}。

GET /api/v1/health

健康检查：服务版本、已加载棋种数、运行时长。

i
终局约定：当前局面没有合法走法时，move 返回 200、move: null、gameOver: true，不会把“已结束”当成 HTTP 错误。
SCHEMA

请求与响应

FEN 棋种与网格棋种共用同一层请求结构。

请求字段 POST /api/v1/move

字段类型说明
gamestring棋种 id，如 xiangqi；路径形式可省略。
position.fenstring象棋 / 国际象棋使用；也可把 fen 放在顶层。
position.boardstring[]网格棋种使用；行优先扁平数组，空格用 ""。
position.turnstring轮到谁走：象棋 w/b，网格棋种见棋种页。
difficultystringeasy / normal / hard / master，默认 normal。
enginestring选择搜索引擎，见下方“引擎选择”；默认使用棋种默认引擎。
timeLimitMsint思考时间上限，50–15000，默认随难度。
maxDepthint最大思考深度，1–10；不传则按难度。
seedint64随机种子，用于部分棋种的等价走法选择。

fen / board / turn 也可以放在顶层；嵌套的 position 优先。

引擎选择 engine

棋种可选引擎（默认在前）
中国象棋加载 NNUE 时 pikafish-nnue / godogpaw / builtin，否则 godogpaw / builtin
国际象棋chess-3 / builtin
其余棋种builtin

传空或 auto 使用默认引擎；不可用的引擎返回 UNKNOWN_ENGINE。/api/v1/games 的 engines 字段列出每个棋种的可选值。

响应字段 data

字段说明
move最佳走法，结构见下方“走法对象”。
engine实际使用的引擎：chess-3 / godogpaw / pikafish-nnue / builtin。
status走完这一步后的状态：playing / check / checkmate / stalemate / win / draw。
gameOver该走法是否直接结束对局。
evaluation评分（centipawn）与视角；将杀时含 mateIn。
search实际深度、节点数、耗时、是否超时、PV 前缀。

走法对象 move

{
  "uci": "h2e2",                  // chess / xiangqi
  "from": { "index": 25, "row": 2, "col": 7 },
  "to":   { "index": 22, "row": 2, "col": 4 },
  "index": { "index": 112, "row": 7, "col": 7 },
  "promotion": "q",               // chess promotion
  "notation": "h2e2",
  "captured": "bP",               // optional
  "flipped": 3,                   // reversi flips
  "jump": true                    // checkers / jungle river jump
}

合法走法 POST /api/v1/legal-moves

请求体与 move 相同，不需要难度与时间。响应中的 position 包含棋盘、FEN（若适用）、状态、全部合法走法。

{
  "ok": true,
  "data": {
    "game": "xiangqi",
    "count": 44,
    "position": {
      "turn": "w",
      "status": { "state": "playing" },
      "legalMoves": [ { "uci": "b0c2" }, ... ]
    }
  }
}

应用走法 POST /api/v1/apply-move

把一步棋应用到当前局面，返回新棋盘、轮次、状态与全部合法走法。move 可以只传 uci，也可以传 index 或 from / to。

{
  "ok": true,
  "data": {
    "game": "xiangqi",
    "move": { "uci": "h2e2", "from": {...}, "to": {...} },
    "position": {
      "fen": "...",
      "turn": "b",
      "status": { "state": "playing" },
      "legalMoves": [ { "uci": "..." }, ... ]
    }
  }
}
PARAMETERS

难度、错误与跨域

思考时间是预算，不保证精确耗时；迭代加深会在超时前保留完整结果。

难度与时间

国际象棋 / 中国象棋由引擎按难度调整深度，master 使用时间限制迭代加深；下表为其余棋种内置引擎的默认值。

difficulty默认深度默认时间适合
easy2300ms快速响应、弱 AI
normal41000ms常规对弈
hard52500ms更强对抗
master76000ms离线分析

各棋种会按分支数调整实际上限；maxDepth 与 timeLimitMs 可覆盖默认值。

错误码

HTTPcode含义
400INVALID_POSITION棋盘 / FEN 格式错误或局面不合法
400BAD_REQUEST缺少参数或 JSON 不合法
400UNKNOWN_ENGINE引擎名不存在或当前不可用（如未加载 NNUE 时请求 pikafish-nnue）
404UNKNOWN_GAME棋种 id 不存在
504TIMEOUT思考超时且没有可用走法
500INTERNAL_ERROR服务内部错误

跨域

所有已注册接口统一经过全局 CORS 过滤器，返回 Access-Control-Allow-Origin: *。普通 JSON、SSE、错误响应和文档资源都包含跨域头；OPTIONS 预检返回 204，并允许 EventSource 重连所需的 Last-Event-ID。

无状态边界

服务端不保存棋谱、不维护会话、不检测三次重复。需要这些能力时，由调用方根据自己保存的历史判断；接口只负责当前局面下的走子计算。
