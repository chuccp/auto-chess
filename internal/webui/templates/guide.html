GETTING STARTED

三步接入

你的应用保留棋盘与历史，服务端只做一件事：在给定局面下计算下一步。

服务地址http://127.0.0.1:8090
核心接口POST /api/v1/move
流式接口GET/POST /api/v1/move/stream
01

读取棋种

从 GET /api/v1/games 获取棋盘尺寸、初始局面、坐标约定和走子格式。也可以直接使用固定 id。

02

提交当前局面

FEN 棋种传 fen；网格棋种传 board 与 turn。可附带难度和思考时间。

03

应用返回走法

响应中的 move 就是下一步。由你的应用落子、记录棋谱、判断终局，再次请求。

请求

POST /api/v1/move
Content-Type: application/json

{
  "game": "xiangqi",
  "fen": "rnbakabnr/9/1c5c1/...",
  "difficulty": "normal",
  "timeLimitMs": 1000
}

也可以把棋种放在路径里：POST /api/v1/games/xiangqi/move。

响应

{
  "ok": true,
  "data": {
    "game": "xiangqi",
    "engine": "godogpaw",
    "move": {
      "uci": "h2e2",
      "from": { "index": 25, "row": 2, "col": 7 },
      "to": { "index": 22, "row": 2, "col": 4 }
    },
    "gameOver": false,
    "status": { "state": "playing" },
    "evaluation": { "score": 32 },
    "search": { "depth": 4, "nodes": 18234, "timeMs": 86 }
  }
}

move 是唯一需要消费的字段。服务端不返回新棋盘。

i
无状态：服务端不保存棋谱或轮次；重复局面、棋钟等规则由调用方维护。
CLIENTS

调用示例

JavaScript

const res = await fetch("/api/v1/move", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    game: "xiangqi",
    fen: "rnbakabnr/9/1c5c1/...",
    difficulty: "normal"
  })
});

const { ok, data, error } = await res.json();
if (ok) console.log(data.move);
else console.error(error.code, error.message);
RUN

运行服务

无需额外服务，要求 Go 1.26+。

go mod tidy
go run .

# Docs & debugger: http://127.0.0.1:8090/
# Core API:          http://127.0.0.1:8090/api/v1/move
# Streaming API:     http://127.0.0.1:8090/api/v1/move/stream
↔
跨域：所有接口都返回 Access-Control-Allow-Origin: *，OPTIONS 预检返回 204。
